# Baseline Reference Environment Specifications

This document defines the exact Windows XP reference baseline environment used to build, compile, and verify all test fixture executables (`artifacts/*.exe`) for **ClassicBasic**.

---

## 1. Host VM & Operating System

- **Operating System**: Microsoft Windows XP Professional, Service Pack 3 (32-bit x86, Version 5.1, Build 2600.xpsp_sp3_qfe.080414-1211)
- **Filesystem Mount**: Mounted directly on the Linux development host at `/mnt/winxp`
- **Remote Automation**: OpenSSH Server (`/mnt/winxp/openssh/`) for automated fixture compilation and binary extraction
- **Source Workspace**: `/mnt/winxp/Src/` (contains fixtures `App01` through `App17`)

---

## 2. Reference Visual Basic 6.0 Toolchain

- **Visual Basic IDE / Compiler**:
  - Microsoft Visual Basic 6.0 Enterprise Edition (Service Pack 6)
  - Compiler Version: Build 8176 (VBA Retail 6.0.8169)
  - Executable: `C:\Program Files\Microsoft Visual Studio\VB98\VB6.EXE`
- **Native Backend & Linker**:
  - MSVC C2 Optimizing Compiler: `C2.EXE`
  - Linker & COFF Binary Dumper: `LINK.EXE` / `DUMPBIN.EXE` Version 6.00.8168 (Copyright Microsoft Corp 1992–1998)
- **Compilation Modes**:
  - **Native Code**: Machine instructions generated by MSVC C2 (`CompilationType=0`), bound to `MSVBVM60.DLL`
  - **P-Code**: Stack-machine bytecode interpreted by `ThunRTMain` via `ProcCallEngine` / `MethCallEngine` (`CompilationType=-1`)

## 4. Clean-Room Methodology Notice

The `/mnt/winxp` reference environment is used **exclusively for compiling fixture binaries and observing external behavior**:
1. Compiling VB6 `.vbp` source files into Native and P-Code `.exe` fixtures via the authentic Microsoft compiler.
2. Generating import/export headers and binding tables via `dumpbin /imports` and `dumpbin /exports`.
3. Validating error codes, HRESULT translations, and edge-case behavior against MSDN public documentation.
4. **Strict Clean-Room Compliance**: Zero proprietary Microsoft code, disassembly, decompilation, or reverse-engineered logic is copied, adapted, or linked into the ClassicBasic codebase.
