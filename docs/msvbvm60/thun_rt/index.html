Visual Basic 6.0 Runtime Main Entry Point and Execution Engines.

Visual Basic 6.0 compiled executables begin execution by calling ThunRTMain. The name originates from “Thunder Runtime Main”, where “Thunder” was Microsoft’s internal project codename for Visual Basic.
