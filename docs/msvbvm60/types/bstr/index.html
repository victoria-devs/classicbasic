COM Automation BSTR representation and heap allocation engine.

A BSTR (“Basic String”) is a pointer to the first UTF-16 code unit of a string. The 4 bytes directly preceding the pointer contain the byte length of the string (excluding the null terminator). The string is also terminated by a null UTF-16 character (0x0000).
