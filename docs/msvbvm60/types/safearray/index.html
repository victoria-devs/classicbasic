COM and Visual Basic 6.0 SAFEARRAY structures.

Visual Basic 6 arrays are represented in memory as OLE Automation SAFEARRAY structures, storing dimension counts, feature flags, lock counts, and boundary descriptors (SAFEARRAYBOUND).
