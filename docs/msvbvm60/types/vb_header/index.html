Visual Basic 6.0 internal header structures.

When a native-compiled Visual Basic 6.0 executable starts, its entry point performs:

    push offset VBHeader
    call ThunRTMain
    ret

The VBHeader struct contains the runtime version, language DLL references, pointer to Sub Main (if any), thread configuration, and pointers to the project tables (ProjectInfo, ObjectTable, GUI descriptions, etc.).
