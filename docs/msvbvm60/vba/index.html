Visual Basic Architecture (__vba*) compiler runtime helpers.

When the Visual Basic 6 native-code compiler (C2.EXE) compiles functions, it generates calls to __vba* helpers for string management, variant arithmetic, array lifecycle, and SEH (Structured Exception Handling).
