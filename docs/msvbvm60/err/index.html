Module err

Structured Error Handling and ErrObject implementation.

Provides the runtime state machine for Visual Basic 6 structured error handling (On Error Resume Next, On Error GoTo <Label>, On Error GoTo 0), runtime error code lookup, and the intrinsic COM ErrObject (Err.Number, Err.Description, Err.Source, Err.Clear, Err.Raise, Err.LastDllError).
