§MSVBVM60 - Visual Basic 6.0 Native Runtime Clone in Rust

Re-implementation and reverse-engineering study clone of Microsoft’s MSVBVM60.DLL (Visual Basic Virtual Machine 6.0).

§Overview of MSVBVM60.DLL

MSVBVM60.DLL is the runtime execution engine for all software built with Microsoft Visual Basic 6.0 (released in 1998, code named “Thunder”). Whether a VB6 program was compiled to Native Code (x86 machine instructions via an optimizing backend based on MSVC C2) or P-Code (interpreted bytecode), it depends directly on this DLL.

§Key Responsibilities:

  1. Application Lifecycle (ThunRTMain):

    • Native VB6 binaries have a minimal entry point that pushes the address of a VBHeader structure and invokes ThunRTMain (“Thunder Runtime Main”, ordinal 100).
    • ThunRTMain validates the "VB5!" magic bytes, initializes COM/OLE apartments, registers SEH exception handlers (__vbaExceptHandler), loads forms/modules, invokes Sub Main or creates the initial Form, and manages the Win32 message pump.

  2. P-Code Interpreter Engines (ProcCallEngine, MethCallEngine):

    • For applications compiled in P-Code mode, execution is interpreted instruction-by-instruction by these engines.

  3. Type System and Object Model:

    • BSTR: Length-prefixed (32-bit byte count at offset -4), UTF-16, null-terminated COM strings.
    • VARIANT: 16-byte tagged unions (VT_I4, VT_BSTR, VT_DISPATCH, etc.) enabling VB6 dynamic typing.
    • SAFEARRAY: Multi-dimensional bounded array descriptors.
    • Currency (CY): 64-bit integer fixed-point with 4 decimal places.
    • COM Interfaces: BASIC_CLASS_*, EVENT_SINK_*, and Zombie_* implement IUnknown and IDispatch.

  4. Memory Manipulation (GetMem*, PutMem*, VarPtr):

    • Since VB6 lacks native pointer syntax, programmers historically used undocumented runtime exports like VarPtr (which passes back a variable’s address) and GetMem4/PutMem4 for direct memory manipulation and high-performance Win32 API interop.

  5. VBA Standard Library (rtc*):

    • Functions like MsgBox (rtcMsgBox), DoEvents (rtcDoEvents), RGB (rtcRgb), InStr (rtcInStr), Trim (rtcTrimBstr), and Shell (rtcShell).

  6. Compiler Runtime Helpers (__vba*):

    • String allocation/copying/concatenation (__vbaStrCopy, __vbaStrCat, __vbaFreeStr).
    • Variant math and conversions (__vbaVarAdd, __vbaI4Str, __vbaVarMove).
    • Array allocation and bounds checking (__vbaAryConstruct, __vbaAryLock).
    • Error handling (__vbaOnError, __vbaExceptHandler).

  7. Calling Conventions:

    • VB6 on x86 utilizes __stdcall (extern "system" in Rust) for the vast majority of exports.
    • Specific CRT math routines (_CI*, _adj_fdiv_*, _allmul) use extern "C".

  8. Export Ordinals (msvbvm60.def):

    • Windows DLLs often link by ordinal. This implementation includes a complete .def file covering all 635 exports ranging from ordinal 100 (ThunRTMain) to 2010 (EbGetVBAObject).
