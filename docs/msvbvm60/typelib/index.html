Clean-room MSFT TypeLib Binary Parser and DISPID Introspection Cache.

Provides parsing for Microsoft Type Library (MSFT) binary blocks embedded within Win32 PE .rsrc sections or standalone .tlb/.olb files.

§Architecture & Clean-Room Specification

  • Header (MSFT_Header): Magic 0x5446534D (“MSFT”), version 0x00010002, nrtypeinfos count, NameOffset, and flags (0x100 signifies presence of help string DLL offset).
  • Segment Directory (MSFT_SegDir): Directory of 15 segments containing pTypeInfoTab, pNametab, pGuidTab, pStringtab, pRefTab, etc.
  • Type Information (TypeInfo): Encodes coclasses, interfaces, dispatch dual interfaces, enums, etc. Maps member names to DISPIDs and parameter signature metadata.
  • DISPID Cache (DispidCache): Fast in-memory index mapping (IID, member_name) -> DISPID and (IID, DISPID) -> FuncDesc for dynamic dispatch and late-binding engines.
