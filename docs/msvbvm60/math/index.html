Math Intrinsics, CRT Floating Point helpers, and Pentium FDIV workarounds.

Visual Basic 6 executables compiled with MSVC backends include calls to MSVC CRT math intrinsics (_CI*) and the historic Intel Pentium FDIV bug software workaround routines (_adj_fdiv_*).
